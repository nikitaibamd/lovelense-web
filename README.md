# Lovelense — мини-апп

Фронтенд Telegram Mini App Lovelense. Отдаётся Cloudflare Worker'ом `lovelense-app`.

- `src/index.template.html` — исходник
- `assets/` — иконки, спрайты питомца, картинки
- `python3 build.py` — собирает `dist/index.html`

Сервер, бот и данные пользователей здесь не хранятся.
